# Roopraj S · Data Analyst Portfolio

Personal portfolio site showcasing data analysis projects built with SQL, Python, Excel and Power BI.

## Publish on GitHub Pages

1. Create a new public repository named `<your-username>.github.io` (or any name).
2. Upload `index.html`, this README and the `assets` folder (it holds the certificate image) to the repository.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/` (or `/<repo-name>/`).

## Update your details

Open `index.html`, find the block marked **EDIT YOUR DETAILS HERE** near the bottom, and fill in:

- `github` – your GitHub profile link (shows the GitHub button)
- `experience` – jobs or internships from LinkedIn (shows the Experience section)
- Certificate details live in the Certification section of the HTML; add new ones by copying that block.
- `repo` on each project – link to that project's repository (shows a "View code" link)
